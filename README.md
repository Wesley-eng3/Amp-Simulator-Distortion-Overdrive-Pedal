# 🎸 Amp Simulator / Distortion / Overdrive Pedal

An analog guitar pedal project developed to emulate the tonal characteristics of classic guitar amplifiers, combining overdrive, distortion, and tone shaping stages into a single circuit.

The project was inspired by the concept behind SAN AMP style pedals, aiming to recreate different amplifier responses and tube-like behavior using a fully analog signal path.

---

# 🔧 Project Features

* Analog amplifier simulation
* Overdrive and distortion stages
* Active EQ section
* Circuit based on TL072 dual operational amplifiers
* 9V DC power supply
* Developed using Altium Designer
* Custom PCB design
* Low-noise optimized layout
* Compatible output for amplifiers, audio interfaces, and mixers

---

# 🧠 Circuit Architecture

The circuit uses TL072 operational amplifiers to perform:

* Signal pre-amplification
* Gain and saturation stages
* Active filtering
* Tone control
* Frequency response shaping
* Tube amplifier-like response simulation

The design was divided into multiple analog stages to provide greater control over:

* Gain
* Presence
* Bass
* Treble
* Saturation
* Dynamic response

---

# 🎛️ Tonal Reference

This project was inspired by classic amp simulator concepts similar to SAN AMP pedals, aiming to reproduce different tonal characteristics commonly found in:

* Clean amplifiers
* Crunch amplifiers
* High-gain amplifiers
* Tube stack-style tones
